# Syntecxhub_Weather_App
A responsive Weather Forecasting Application developed using React. The application fetches real-time weather data from an external API and displays current weather conditions along with forecasts for different cities.

# Weather Forecast Application 
developed by Renuka Areti

## Features
- Search weather by city
- Real-time weather data
- Weather forecast
- Error handling
- Responsive UI

## Technologies Used
- React JS
- CSS
- OpenWeather API
